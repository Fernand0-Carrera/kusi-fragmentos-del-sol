# Guion del video demo (45 a 90 segundos)

El enunciado pide mostrar gameplay, menús, audio y funcionalidades. Graba con el sonido del sistema activado (por ejemplo, con OBS Studio o la grabadora de Windows con Win + Alt + R).

| Tiempo | Qué mostrar |
| --- | --- |
| 0–8 s | Menú principal con la música; mostrar récord y nivel alcanzado. Abrir "Cómo jugar" un instante. |
| 8–16 s | "Nueva partida": dos paneles de la historia y luego "Saltar historia". |
| 16–34 s | Nivel 1: recoger fragmentos, pisar un Neblino, usar la flor de puya y encender una apacheta. Caer a un pozo para mostrar la reaparición. |
| 34–40 s | Pausa (P): mostrar el menú y silenciar/activar el sonido. Continuar. |
| 40–52 s | Nivel 2: suelo de hielo resbaloso y una losa móvil sobre el abismo. |
| 52–75 s | Nivel 3: pelea con Uku, esquivar esquirlas y pisarlo aturdido; mostrar la barra de vida y el minimapa. |
| 75–85 s | Puerta del Sol, epílogo y pantalla de victoria con el récord. |
| 85–90 s | Opcional: el juego en el móvil o con `?tactil` mostrando los controles táctiles. |

Consejo: para grabar el nivel 3 sin rejugar todo, elige "Continuar" en el menú cuando tengas guardado el nivel 3.
